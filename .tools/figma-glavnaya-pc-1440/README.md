# Главная PC 1440 (Figma → локальная вёрстка)

Макет: [Untitled, node `6:1680`](https://www.figma.com/design/ShbRIAPaQTkatEXyjQD22b/Untitled?node-id=6-1680)

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Полная главная в режиме Figma 1440: сборка лендинга + высоты секций как на артборде |
| `figma-document.css` | Правки под линейный скролл и фиксированные высоты секций |
| `figma-mcp-header-hero.html` | Статичный фрагмент (шапка + hero) для быстрой сверки |

## Как открыть

1. Ширина окна — **1440 px** (или DevTools → Responsive → 1440×900).
2. Откройте `index.html` в браузере (двойной клик или Live Server).

При необходимости пересоберите лендинг в **рабочей** копии темы (`npm run build` в `landing-src`), затем обновите страницу.

## Ограничение Figma MCP

При выгрузке сработал дневной лимит MCP. Полный статический HTML на 9600 px из одного ответа Figma не собран — используется уже сверстанный лендинг темы (сетка 1440 px) в режиме сравнения с артбордом.
